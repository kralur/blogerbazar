# Короткий прогон перед рекламой — 15 пунктов

Сокращённая версия `docs/rc-qa.md` (40 пунктов) для прогона с телефона за 30–40 минут. Полный чек-лист остаётся
источником истины; этот список покрывает то, без чего рекламу запускать нельзя. Отмечать как в `rc-qa.md`:
`[x]` прошло, `[!]` баг, `[-]` не проверялось.

Нужны **два** Telegram-аккаунта: **A** (бизнес) и **B** (блогер). Для п. 15 ещё **C** (бренд-фейс) или B со сменой
роли. Прогон делать на iOS и Android, хотя бы один раз на каждом.

**Если что-то не так:** номер пункта, что ожидали, что увидели, скриншот. Этого достаточно, остальное я найду сам.

## Автопрогон 2026-11-07 (Claude, локальная копия с тестовыми данными)

Шаги 2–11 и 15 пройдены скриптом (действия через API и экраны приложения в Playwright, 30 скриншотов): профили
бизнеса, блогера и бренд-фейса, кампания, отклик, принятие, сделка с контактами, оффер, завершение (бизнес не может
завершить без цены, с ценой сделка завершается), отзывы скрыты до второго и видны после, жалоба в админке и её решение,
обзор админки с источником `test_launch`, сделка с бренд-фейсом. Ошибок не найдено. Остались только пункты, где нужен
настоящий Telegram: 1 (ссылка и `/start`), сообщения бота в 5–9, 12–14 и устройства iOS и Android.

## Перед прогоном (владелец, 20 минут)

- [ ] 2FA: Telegram, GitHub, Railway, Cloudflare.
- [ ] Railway → Postgres → Backups: ежедневное расписание включено.
- [ ] Railway → API → Variables: `Database__ApplyMigrationsOnStartup` = `true`.
- [ ] Mini App → Админка → «Безопасность»: скриншот (пусто или нет) для решения о строгом CSP.

## Прогон

1. [ ] **Открытие по рекламной ссылке.** A открывает `t.me/<бот>?start=test_launch` → `/start` отвечает с кнопкой
   «Открыть», приложение открывается за 2–3 секунды, без белого экрана; язык и тема как в Telegram.
2. [ ] **Регистрация бизнеса.** A: телефон из Telegram → роль «Бизнес» → анкета → профиль сохранён. Telegram один
   раз спросил «Разрешить боту писать?» → разрешить.
3. [ ] **Регистрация блогера.** B: роль «Блогер» → анкета → сразу виден в каталоге блогеров у A. Фото профиля:
   добавить, заменить, удалить.
4. [ ] **Кампания.** A: «+ Создать» (город, категории, бюджет, срок) → кампания видна у B на главной и в
   «Кампаниях». Прошедшую дату выбрать нельзя.
5. [ ] **Отклик.** B откликается → A получает сообщение бота с кнопкой, кнопка открывает отклики; A видит
   «Посмотреть отклики · 1», B видит отклик в «Заявки».
6. [ ] **Сделка.** A принимает отклик → сделка создана, B получает сообщение бота; у обоих в сделке контакты
   партнёра и «Написать в Telegram». Отклонение второго отклика: B получает сообщение, статус «Отклонён».
7. [ ] **Оффер.** A открывает профиль B → «Предложить сотрудничество» («Заполнить из кампании» подставляет
   данные) → B получает сообщение бота «ответить в течение 48 часов» → принимает → вторая сделка.
8. [ ] **Завершение.** B завершает сделку → A получает сообщение. A завершает со своей стороны: приложение
   **требует указать цену** (0, если без оплаты) → статус «Завершена» у обоих.
9. [ ] **Отзывы.** B ставит отзыв → A получает сообщение, отзыв ещё скрыт. A ставит отзыв → оба опубликованы,
   рейтинг блогера и бизнеса обновился на профилях.
10. [ ] **Жалоба.** B жалуется на профиль A (причина + комментарий) → у владельца в Админка → Жалобы;
    «Решить» убирает её из открытых.
11. [ ] **Админка.** Владелец: Mini App → Админка: цифры обзора правдоподобны, в «Источниках» на сайте виден
    `test_launch`; кнопка «Полная админка» открывает сайт, вход через Telegram работает, «Обзор» и «Воронка»
    показывают сегодняшние действия.
12. [ ] **Узбекский.** B: Настройки → язык UZ → все экраны на UZ, без русских остатков; `/start` в боте на UZ.
    Вернуть RU.
13. [ ] **Тема.** Настройки → «Тёмная», «Светлая», «Как в Telegram» → всё читаемо, шапка и нижняя панель
    Telegram не сливаются; после перезапуска выбор сохранён.
14. [ ] **Ошибки.** Чужая сделка по ссылке → «Не найдено» (не «Нет доступа»). Режим полёта → экран ошибки с
    «Повторить», без белого экрана; после включения сети «Повторить» работает.
15. [ ] **Бренд-фейс.** C: роль «Лицо бренда» → анкета с фото → виден в каталоге бренд-фейсов; A предлагает
    сотрудничество бренд-фейсу → C принимает → сделка, контакты видны только в сделке.

## После прогона

- Удалить тестовые кампании и сделки не нужно: они войдут в статистику как тест, метка `test_launch` их выделит.
- Если все 15 прошли: включать рекламу с небольшим бюджетом на 2–3 дня и смотреть воронку на сайте.

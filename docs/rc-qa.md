## 1. Онбординг и разрешение боту писать

Ручной модерации нет: профили блогера и бизнеса одобряются автоматически при сохранении анкеты.

- [ ] Первый запуск: выбор языка есть в анкете; при редактировании профиля его нет.
- [ ] После анкеты Telegram спрашивает «Разрешить боту писать вам?» — один раз на устройстве. Разрешить.
      Если ответить «нет» и ни разу не открыть чат бота, сообщения бота не придут (ограничение Telegram).
- [ ] B заполняет анкету блогера → сразу виден в каталоге блогеров.
- [ ] A заполняет профиль бизнеса → его кампании видны в каталоге.
- [ ] C заполняет профиль бренд-фейса → виден в каталоге бренд-фейсов.
- [ ] Фото профиля: «+» → выбор из галереи; «Заменить»/«Удалить» в меню (у Business и Brand Face — отложенный
      вопрос из QA-раунда 4, зафиксировать фактическое поведение).

## 2. Основной цикл: кампания → отклик → сделка → завершение → отзывы

- [ ] A: «+ Создать» кампанию (город, категории, бюджет, срок). Прошедшую дату выбрать нельзя.
- [ ] Кампания видна B в «Кампаниях» и на главной.
- [ ] B откликается → A получает сообщение бота «новая заявка»; кнопка в сообщении открывает приложение.
- [ ] A видит отклик в «Посмотреть отклики · N»; B видит его в «Заявки → Отклики».
- [ ] A принимает отклик → создаётся сделка; B получает сообщение бота; обе стороны видят сделку в «Заявки → Сделки».
- [ ] В сделке видны контакты партнёра и «Написать в Telegram» (только участникам сделки, D31).
- [ ] Одна сторона завершает сделку → вторая получает сообщение бота; статус «Завершена» у обоих.
- [ ] B оставляет отзыв → A получает сообщение «партнёр оставил отзыв»; отзыв ещё **не** опубликован.
- [ ] A оставляет отзыв → оба отзыва опубликованы (рейтинг блогера и бизнеса обновился).
- [ ] Отклонение отклика: B получает сообщение бота, статус в «Откликах» — «Отклонён».

## 3. Оффер: предложение с профиля блогера

- [ ] A открывает профиль B → «Предложить сотрудничество»; кнопка не перекрывает отзывы.
- [ ] «Заполнить из кампании» подставляет бюджет, срок и текст.
- [ ] B получает сообщение бота с кнопкой «ответить в течение 48 часов» (RU + UZ в одном сообщении).
- [ ] `/start` в чате бота → приветствие на языке приложения с кнопкой «🚀 Открыть» / «🚀 Ochish»; кнопка открывает приложение.
- [ ] Сменить язык в Настройках на UZ → следующее уведомление и `/start` приходят только на узбекском; обратно на RU — только на русском.
- [ ] Кнопка «Открыть / Ochish» в каждом уведомлении ведёт на нужный экран (отклики кампании, сделка, отклик, оффер).
- [ ] B принимает → сделка создана, A получает сообщение. Отдельно: B отклоняет → A получает сообщение.
- [ ] Повторный оффер тому же блогеру, пока первый активен → понятная ошибка («уже есть активное предложение»).

## 4. Граничные случаи

- [ ] Кампания с прошедшим сроком: нет в каталоге; по прямой ссылке — серый бейдж «Срок истёк» без кнопки отклика.
- [ ] Добавить себя в избранное нельзя (кнопки на своём профиле нет).
- [ ] Чужая сделка по ссылке `#/deal?id=…` → «не найдено» (не «нет доступа»).
- [ ] Нет сети / сервер недоступен → экран ошибки с «Повторить», без белого экрана.

## 5. Настройки, язык, тема

- [ ] Профиль → «Настройки»: язык RU/UZ меняется сразу на всех экранах.
- [ ] Тема: «Как в Telegram» / «Светлая» / «Тёмная»; после перезапуска выбор сохраняется.
- [ ] Тема приложения отличается от темы Telegram → шапка и нижняя панель Telegram читаемы.
- [ ] Выйти → экран приветствия; Удалить аккаунт → подтверждение, затем профиль недоступен.
